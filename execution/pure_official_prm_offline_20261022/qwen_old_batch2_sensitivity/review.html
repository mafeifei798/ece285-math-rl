  • 固定原始 288 条文本、步骤、组结构、actor 位置重构、0.5 权重、温度 0.1、固定宽度 2048、RLOO 和仅一次全批次 whitening；KL 固定 0。
  • Qwen 使用官方 chat + <extra_0>；PURE 使用官方模型卡的题目原文 + 逐步追加换行打分。另列 PURE 官方 RL 提示词敏感性结果，两者不混合挑最好。
  • PURE signed 分是 p₁−p₀，不是把 signed 分再做 2r−1。CPU 独立 return / advantage oracle 与官方函数一致。
  • canonical 步骤与旧 Qwen 保持一致；旧 rollout 没有原始 emitted token IDs。因而不是完整官方 RL 输入逐 token 重现，也不是历史 A/B advantage 的复算。
  • 这批样本围绕历史空回答所在批次抽取，不代表总体；没有新的人工过程标注，不能宣称过程准确率改善。
