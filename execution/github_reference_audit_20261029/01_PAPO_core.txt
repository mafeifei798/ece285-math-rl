345:     """
346:     PA_GRPO (Process-Aware GRPO): Dual-objective advantage computation.
347: 
348:     Decomposes advantage into two independently normalized components:
349:         A_total = A_out + lambda_process * A_proc
350: 
351:     - A_out: standard GRPO advantage from binary rule-based rewards
352:     - A_proc: process advantage from PRM scores, normalized ONLY among correct responses
353:     - lambda_process: fixed weight for process advantage (default 1.0 = equal weight)
354: 
355:     Args:
356:         token_level_rewards: (bs, response_length) binary rule-based rewards
357:         response_mask: (bs, response_length) mask for valid tokens
358:         index: (bs,) group IDs for each response
359:         reward_prm: (bs,) PRM scores (0, 0.5, 1) from non_tensor_batch
360:         lambda_process: weight for process advantage (default 1.0)
361:         epsilon: small value to avoid division by zero
362:         norm_adv_by_std_in_grpo: whether to normalize by std (True=GRPO, False=Dr.GRPO)
363:         acc: (bs,) binary accuracy from non_tensor_batch, used for correct_mask
364:              when reward shaping (e.g. DAPO overlong penalty) makes scores_rule non-binary.
365:              If None, falls back to scores_rule == 1.0.
366: 
367:     Returns:
368:         advantages: (bs, response_length) token-level advantages
369:         returns: (bs, response_length) same as advantages (outcome-only)
370:         metrics: dict of logging metrics
371:     """
372:     scores_rule = token_level_rewards.sum(dim=-1)  # (bs,)
373:     scores_prm = torch.tensor(reward_prm, dtype=scores_rule.dtype, device=scores_rule.device)
374: 
375:     # Build global binary correctness mask (unaffected by reward shaping)
376:     if acc is not None:
377:         binary_acc = torch.tensor(acc, dtype=torch.bool, device=scores_rule.device)
378:     else:
379:         binary_acc = None
